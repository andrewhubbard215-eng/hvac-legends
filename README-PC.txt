HVAC Allstars  —  PC classroom (separate from the phone app)
============================================================

PHONE APP
  Clock In on a phone / tablet, or the Android AAB.
  Tight glass: drawers, zoom close-up, tap-to-land.

PC CLASSROOM (this folder)
  Full bench: parts tray LEFT, system in the MIDDLE, gauges / DMM RIGHT.
  Electrical: ladder + meter both on screen. Land lugs still zoom the device.

HOW TO OPEN THE PC VERSION
  1. Double-click  PLAY-PC.bat
     (serves this folder, opens the PC bench, writes the student Wi-Fi address)
  2. Or double-click  START-WINDOWS-APP.bat
  3. Shop floor → Classroom Wi-Fi  to copy the phone address
     Same Wi-Fi. Leave the black window open. Windows: Allow on the firewall if asked.

SHOP FLOOR TOGGLE
  Clock In → "PC bench" / "Phone layout" in the header.
  Title card also has  PC classroom · full bench.

If Windows blocks the .bat: right-click → Properties → Unblock → Run anyway.
