HVAC Legends

Privacy policy

Last updated September 26, 2026. HVAC Legends is a vocational trainer for trade students and working techs. It is not directed at children under 13.

What stays on this device

There is no cloud account for the core labs. The app keeps these on this device:

  • Callsign
  • Locker photo, if you set one
  • Password hash
  • XP
  • Lab progress
  • Material notes

Clearing app storage, or the in-app locker reset, deletes that data on this device. The password is stored as a hash on the phone. The core labs do not upload it.

What we do not collect

  • Not collected for ads.
  • No advertising ID.
  • No sale of data.
  • No precise location.

The Android app asks only for INTERNET and VIBRATE.

Optional features that use the network

Shop chat, a class PIN, and a review note use the network only when you choose them. What you type, including the callsign you used, can be shown to the people in that chat or class. A review note is a note you send about the app. If the network is down, those wait on the phone and send later. You can run the core labs without any of them.

Photos and label help

Do not photograph customers, children, or nameplates without permission. Label help is for the unit the tech is allowed to service. A locker photo stays on this device unless you delete the locker.

Callback bomb

“Callback bomb” means a Saturday HVAC no-cool. It is not a weapon and not an explosive.

EPA 608 drills

EPA 608 drills are practice. They are not the official proctored exam and they are not legal advice.

Shop language

Mild shop language can appear in the optional coach roast.

Delete your data

Use the locker reset on this device: on the locker screen, type the callsign and tap Forgot password · reset this locker on this device. That clears that locker on this phone.

Or use Android Settings → Apps → HVAC Legends → Storage → Clear storage. That removes the locker, lab progress, and material notes stored by the app on this device. There is no separate cloud account to close for the core labs.
